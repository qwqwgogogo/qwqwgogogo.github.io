一个知识图谱 Web 应用，原前端用力导向布局（cytoscape `cose`），每次点开节点整图重新做物理模拟 → 节点重叠、分布不均、每次展开整图乱动。改成同心圆环布局。

## 问题分析

**力导向布局**（cose）是"物理模拟摊开"，新节点在父节点旁随机撒点再被弹开 → 无规律、重叠、每次展开全图乱跳。

## 改造方案

按 BFS 算好的 `depth` 分层定半径、每层按 label 排序均分角度、`arcSep` 保证同层不重叠。

## 致命 Bug：坐标系混用

首版用了**容器像素坐标**（圆心=clientWidth/2、半径乘 fitScale），实测发现节点全挤成一坨。

**根因**：布局几何依赖"容器实时像素尺寸" + "fit 缩放"双重缩放，两者打架。

具体：用 `clientWidth/clientHeight` 当圆心和半径基准，再乘 `fitScale = min(1, (min(W,H)/2-90)/(maxR+20))`。若容器此时未量到尺寸（W 或 H 很小），`fitScale` 算出**负值** → 半径全变负 → 所有节点被翻到中心堆成一坨。

## 正确姿势

**布局用纯模型坐标（原点在 (0,0)），半径只由结构决定，让 `fit()` 做唯一一次缩放适配。**

同心圆算法核心（对任意 depth 层）：
- **半径**：`Math.max(baseStep * d, (count * arcSep) / (2π))` → 保证深层不叠、同层不叠
- **角度**：每层从顶部起均分 `2π/count`，奇层错开半格让环间交错
- **同层按 label 排序** → 节点增删时顺序稳定不跳

## 验证方法

写独立 node 脚本 mock 掉 cytoscape，用 4 个场景（正常/深层稀疏/宽环/多根）断言"同层等半径、层间半径递增、角度均分、不重叠"——4 个 PASS。

## 关键结论

1. **画图工具/布局的坐标系，要么纯模型坐标、要么纯像素坐标，别混用**
2. 改 UI 后要独立脚本断言几何性质 + 浏览器实测双验证
3. "整齐"有 3 种含义（树状/同心环/只修重叠），先对齐需求再动手
