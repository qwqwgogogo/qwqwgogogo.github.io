## 一句话

浮点数就是**二进制版的科学计数法**：`(-1)^S × M × 2^E`。32 个格子怎么分给符号、阶码、尾数，决定了它能表示多大范围和多少位精度——这是一个此消彼长的分配题。

## 单精度怎么摆

| 字段 | 位数 | 表示法 | 作用 |
| --- | --- | --- | --- |
| 符号 `S` | 1 | — | 0 正 1 负 |
| 阶码 `E` | 8 | 移码，偏置 **127** | 决定范围 |
| 尾数 `f` | 23 | 原码小数，隐藏最高位的 1 | 决定精度 |

规格化数的真值：

```
X = (-1)^S × 1.f × 2^(E - 127)
```

**隐藏位**是这里最划算的一笔设计：二进制规格化数小数点左边一定是 `1`，那就干脆不存它，23 位尾数白赚一位有效数字，实际精度是 24 位。

## 偏置值：127 还是 128

这里最容易混，因为两本教材口径不一样：

- **通用浮点格式**（唐朔飞教材里的「短浮点数」）：8 位阶码用移码，偏置常数取 `2^(n-1) = 128`，形式上和「补码符号位取反」完全对应。
- **IEEE 754**：偏置取 `2^(n-1) - 1 = 127`。

754 少取 1 是有原因的：8 位阶码能表示 `0..255`，而全 0 和全 1 都要留给特殊值，可用的是 `1..254`。减 127 之后指数真值正好落在 `-126..127`，正负两边不对称但配合非规格化数能把最小值平滑接上去。**看到「偏置 128」先确认它说的是通用格式还是 754。**

## 五种编码：全 0 和全 1 不是数

阶码的两种极端取值被征用了，解释规则整个换一套：

| 阶码 `E` | 尾数 `f` | 含义 | 真值 |
| --- | --- | --- | --- |
| `1..254` | 任意 | 规格化数 | `(-1)^S × 1.f × 2^(E-127)` |
| 全 0 | 全 0 | 零 | `±0`（符号位还分正负零） |
| 全 0 | 非 0 | **非规格化数** | `(-1)^S × 0.f × 2^-126`，隐藏位变成 0 |
| 全 1 | 全 0 | 无穷 | `±∞` |
| 全 1 | 非 0 | 非数 | `NaN` |

非规格化数是这里最反直觉的一格：阶码全 0 时**不做减 127 的转换**，指数固定按 `-126` 算，隐藏位从 1 变成 0。它的作用是填补 0 和最小规格化数 `2^-126` 之间那段空白，让下溢不是「啪一下掉到 0」而是逐步变粗。最小的正非规格化数是 `2^-149`（尾数只有最低一位是 1）。

能表示的最大正数：`S=0, E=254, f 全 1` → `(2 - 2^-23) × 2^127`。

双精度同理：1 位符号 + 11 位阶码（偏置 **1023**）+ 52 位尾数，隐藏一位后 53 位有效。

## 为什么 0.1 存进去就错了

十进制小数转二进制用「乘基取整」：

```
0.3 × 2 = 0.6 → 0
0.6 × 2 = 1.2 → 1
0.2 × 2 = 0.4 → 0
0.4 × 2 = 0.8 → 0
0.8 × 2 = 1.6 → 1
0.6 × 2 = 1.2 → 1   ← 开始循环
```

小数部分永远得不到 0，`0.3` 的二进制是 `0.0100 1100 1100 1100...` 无限循环。尾数只有 23 位，必须截断，所以**存进去的那一刻就已经不是 0.3 了**。`0.1 + 0.2 != 0.3` 不是哪门语言的 bug，是二进制表示的固有性质。

整数不一样：只要位数够，整数在浮点里可以精确表示（超过 24 位有效之后才会开始丢低位）。

## 定点 vs 浮点

| | 定点数 | 浮点数 |
| --- | --- | --- |
| 小数点 | 位置固定 | 位置随阶码移动 |
| 决定范围的 | 总位数 | 阶码位数 |
| 决定精度的 | 总位数 | 尾数位数 |
| 连续的数 | 是 | 不是（越靠近 0 越密） |
| 表示 0.1 | — | 不精确 |
