## I/O 系统管的是哪件事

输入输出系统是一个软硬件结合的子系统，负责管理和优化 CPU、主存与外围设备之间的数据流动。它的物质构成至少有四层：外设本体、外设的接口电路、设备控制器（再往上还有 I/O 控制器和通道这类智能部件），以及驱动这些硬件的软件。职责也可以拆成三条：在主存与外设之间铺一条足够快的传输通路；把用户提出的 I/O 请求翻译成设备能执行的控制命令；给每台外设分配可识别的地址，让 CPU 能够准确选中要访问的那一台。硬件与软件必须协同，才能保证数据在主机与外设之间传得既正确又快。

后面几节就是按这条线展开的：先盘外设本身，再讲外设怎么挂到主存与 CPU 能够到的互连结构上，然后是接口、端口编址，最后落到主机与外设交换数据的几种控制方式。

## 第一种口径：按数据流向

外设是计算机与用户或者其他机器交换信息的桥梁。它一方面把外部环境的数据和指令收进来，转换成计算机内部能处理的二进制形式；另一方面把处理结果以人能读懂的形式送出去。

**输入设备**的任务是从外界获取信息：键盘和鼠标提交文本与命令，扫描仪和数码相机把图像采样成数字信号，麦克风把声波变成数字音频，传感器和测量仪器把温度、压力、位置这类物理量先变成电信号再变成数字量。

**输出设备**把结果呈现出去或者发送给别的系统：显示器和投影仪出文字、图形和视频，打印机把文档图像落到纸上，扬声器和耳机把数字音频还原成声波，控制器与驱动器把数字指令变成物理动作，例如机械臂的位移。

**输入输出设备**（也直接写作 I/O 设备）双向都能做：磁盘驱动器、磁带机、光盘驱动器既能读出也能写入，网络适配器既收数据也发数据。判断类别时看的是这台设备在系统里承担的方向，而不是它的物理外形——同一个磁盘在文件系统里是存储设备，从数据流向看它是双向设备。

## 第二种口径：按功能与用途

从计算机如何管理和使用设备的角度，外设分成三类。

| 类别 | 作用 | 典型设备 | 传输单位 |
| --- | --- | --- | --- |
| 人机交互设备 | 用户直接输入命令数据、接收反馈 | 键盘、鼠标、触摸屏、显示器、打印机 | 字符 |
| 存储设备 | 断电后长期保存数据和程序 | 硬盘、固态硬盘、U 盘、光盘、磁带 | 块 |
| 机-机通信设备 | 计算机之间传数据，组网的基础 | 网卡、调制解调器、路由器、交换机、数模与模数转换器 | 帧或报文 |

人机交互设备以字符或者行为基本单位传数据，因此常被称为字符型设备。存储设备一次传送多个字节组成的一整块数据，属于典型的块设备。机-机通信设备里除了整机之间的网络设备，还包括做信号形式转换的 DAC 与 ADC，它们让数字系统和模拟世界能够接上头。

还有一种按所处理信息形态的分法：处理数字与文字的设备、处理图形与图像的设备、处理声音与视频的设备。这种口径不改变硬件结构，只是说明数据表示与带宽需求差别很大——文本设备慢到每秒几个字符也能工作，音视频设备则要求持续稳定的高吞吐。

## 第三种口径：字符设备与块设备

分类口径里最影响操作系统与 I/O 硬件设计的是字符与块之别。字符型设备的输入输出以一个字符为最小单位，不要求随机定位到某个固定大小的数据段，速率低且随时可能停；块设备以固定大小的数据块为单位，可以按块号寻址，一旦启动就能连续传很久。前者对应终端、打印机这类设备，后者对应磁盘、光盘、磁带这类设备。这也解释了为什么后面的控制方式里，字符设备多用程序查询或者中断逐字符传送，块设备更适合 DMA 成批传送。

## 外设的三大共性特点

**异步性**。外设与 CPU 的运行节奏不一致，两者不共享同一根时钟，速度差异可以达到几个数量级。外设的操作独立于 CPU 的控制周期，却又要在合适的时刻响应 CPU 发来的控制命令。为了不拖累 CPU，输入输出操作必须能与 CPU 并行执行，做到 CPU 与外设并行、外设与外设也并行。异步性是这条设计的起点：正因为不同步，才需要握手、状态位、缓冲和中断。

**实时性**。一台机器上同时挂着高速与低速外设，CPU 必须适应各不相同的传输速率和传输方式，及时收或发数据。慢了，高速设备的空闲等待就是浪费；跟不上，低速设备的数据就会丢失。所以输入输出系统要有可保证的实时响应能力，而不是尽力而为。实时性还带来一个容易被忽略的后果：设备的就绪时刻是不可预知的，键盘什么时候被按下由用户决定，磁盘什么时候转到位由机械运动决定，因此查询式的做法天然存在延迟，只有把主动权交给外设（由它发请求）才能把延迟压到最短。

**多样性**。外设种类极多，从简单的键盘到复杂的磁盘驱动器，物理特性与信息格式各不相同，主机与外设的连接复杂度随之上升。解决思路是标准化接口：外设通过各自的设备控制器连到统一的标准接口上，主机只面对标准接口和统一的控制命令，不必了解某台设备的具体细节。标准化接口既降低了主机的复杂度，也让新设备可以按同一套规则接入。设备控制器是这种抽象的执行者，它贴在总线与设备之间，把设备特有的信号、格式和时序翻译成人人可认的总线信号。

| 特点 | 直接后果 | 系统提供的手段 |
| --- | --- | --- |
| 异步性 | 无法用统一节拍约定收发时刻 | 握手信号、状态标志、数据缓冲 |
| 实时性 | 高速设备怕等、低速设备怕丢 | 中断、DMA、多重中断与优先级 |
| 多样性 | 连接与格式无法逐一适配 | 标准化接口、设备控制器、驱动软件 |

应对这三个特点的典型手段连起来就是输入输出方式的演进路线：缓冲技术吸收速率差，中断机制让 CPU 不必死等，DMA 让整块数据绕过 CPU 直接进主存，再往上还有 I/O 通道和 I/O 处理器这类专门处理外设事务的智能部件，把成批的输入输出任务从主 CPU 上卸载下来。

## 速度差具体差在哪

外设与主存、CPU 之间的速度差不是百分之几十，而是几个数量级：低速设备每秒只产生几个字符，高速磁盘一旦启动可以连续传很久，量级上从每秒几个字符一直到每秒上百兆字节。同一台机器上并存这两种设备，就意味着输入输出组织必须同时容纳两种完全不同的节奏。

这个速度差直接派生出三条设计约束。其一是缓冲：主机一秒能给出的数据，打印机几十秒才消化得完，中间必须有一段暂存空间，否则要么丢数据要么让 CPU 停下来等。其二是单位：以字符为单位交换数据的设备与以数据块为单位交换数据的设备，适合的传送方式不可能一样，前者一次中断搬一个字符还算得过来，后者如果也逐字走中断，中断本身的开销就会超过数据传输。其三是并行：外设的动作（机械运动、光学采样、信号转换）本身很慢，只有让它与 CPU 各自跑各自的，主机时间才不会被外设吞掉。

## 为什么这一章总是软硬件混着讲

外设这一层的特殊性在于：同样的物理动作，可以用硬件做、也可以用软件做，代价完全不同。设备准备好一个字符后，是让 CPU 反复来问（软件查询），还是让接口主动发信号（硬件请求），前者省硬件费 CPU，后者反过来。缓冲区放在接口里就要多花芯片面积，放在主存里就要占用总线和内存带宽，两种放法都被真实机器采用。

所以看这一节的任何机制时，先问一句「这一步谁在做」：地址译码、数据锁存、状态记录通常由接口的硬件顺手做完；决定何时读、读完怎么处理、出错怎么恢复则交给软件。硬件负责快，软件负责灵活，输入输出方式的演进就是把这条分界线反复往硬件一侧挪——从查询到中断，从中断到 DMA，从 DMA 到通道，每次挪动都是为了把主 CPU 从数据搬运里解放出来。

## 容易混的三处

第一，输入输出设备与外设不是同义词：外设是设备本体，主机一侧必须还有设备控制器和接口，两者合起来才构成一条可用的通路。第二，人机交互设备与输入设备是两套口径的交叉，键盘既属于输入设备也属于人机交互设备，答题时要按题目问的口径回答。第三，存储设备与主存不是同一层：硬盘、光盘虽然也叫存储设备，但属于外部存储，特点是容量大、速度慢、断电不丢信息，与主存在访问方式和寻址单位上都不同。

同一台物理设备在不同口径下会被归进不同的格子，这在考试里是常见的混淆点。判断口径的线索是提问用的词：问数据流向就看它能不能反向传，问功能就看它是给人用、存数据还是联网，问信息形态就看它处理的是文字、图形还是音视频。三个口径彼此独立，不能互相推导，也不需要背成一张唯一的表。
