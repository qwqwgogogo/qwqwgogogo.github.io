## 一句话

总线是**共享**的传输线：所有部件挂在同一组线上，同一时刻只能有一个发送者说话。共享带来省线，也带来两件必须解决的事——谁先说（仲裁）和怎么说（定时）。它如同城市里的交通主干道，让各个区域的信息顺畅流通，前提是车辆按规则排队通行。

## 三组线，按功能分

| 线组 | 方向 | 传什么 |
| --- | --- | --- |
| 数据线 | 双向 | 实际内容，根数即总线宽度 |
| 地址线 | 单向 | 指向谁，根数决定可寻址范围 |
| 控制线 | 有入有出 | 读、写、中断请求、总线请求、时钟、复位 |

数据总线在 CPU 与存储器或者 I/O 设备之间传送实际数据，它的宽度（数据线根数）决定一次能搬多少位：32 位数据总线一次传 32 位，64 位一次传 64 位，宽度直接影响数据传输速率。地址总线指出要访问的内存地址或者端口地址，根数决定寻址能力，32 条地址线理论上可寻址 2 的 32 次方个地址单元，即 4 GB 空间。控制总线传送读/写、中断、总线请求与授权一类的信号，用来协调 CPU、主存和 I/O 设备之间的操作。

按连接范围分：**片内总线**在芯片内部连各个元件，例如 CPU 芯片里把寄存器、指令部件、ALU 连起来的内部通路，指令从主存加载进来后就靠它迅速送到执行部件。系统总线跨越芯片界限，连 CPU、主存（RAM 与 ROM）和各种 I/O 模块，通常又拆成数据总线、地址总线、控制总线三组，是系统里最关键的总线，负责在 CPU、存储器和 I/O 设备之间传输数据与指令。再往外是连接外设接口控制器的 I/O 总线，以及跨机器的通信总线。分层的原因是速度差：让慢设备去抢 CPU 到主存那条高速总线，整台机器都得跟着等。

## 地址数据复用

为了节省芯片引脚与线路资源，同一组线可以在不同时刻分别传地址和传数据，这种设计叫地址数据复用。它需要额外的多路复用器与解复用器，还要有定时信号说明此刻线上是地址还是数据：早期处理器就用 ALE（地址锁存允许）信号区分这两个阶段。代价有三层——一次传输要先发地址再发数据，等效带宽直接对折；增加了设计复杂性与信号相互干扰的可能；现代高性能系统因此更倾向于独立的地址线与数据线，用多几根线换更低的延迟。算带宽题时，题目一提到复用，就要记得把地址阶段扣掉。

## 同步总线：公共时钟定一切

传统的总线大多是同步总线，挂接在上面的所有设备都从同一根时钟线取定时信号。传输协议相对简单：一次传输占几个时钟周期事先约定，数据的开始与结束严格跟着时钟脉冲，地址与数据的传输、设备间的应答与确认都落在预定义的时钟周期内，控制器只管按点发。

一个典型安排是这样：处理器作为主控设备在第一个时钟周期把地址和读命令放到总线上，存储器作为从动设备在第 5 个时钟周期把数据送上总线，处理器也在第 5 个周期从数据线上取走数据。这种约定下不需要额外的应答线，代价是那 4 个周期的间隔必须按最慢的器件写死。同步总线通常采用并行传输，同一时刻通过 8 条、16 条、32 条或者 64 条数据线同时送出多个数据位，因此速率可观。

同步通信由公共时钟定节拍，速度快、控制简单，但要求所有挂在这个总线上的设备速率接近，而且**最长的那台决定整体节拍**。它的三个限制要记牢：

- **速度被最慢的设备锁死**。时钟频率必须迁就所有设备中最低的那个速度，才能保证每台都有足够时间响应或者处理信号；设备存取时间相差越大，总线效率越低。
- **时钟偏移**。信号传播需要时间，总线越长，时钟信号到达总线上不同位置的设备就越有先后，这个偏差就叫时钟偏移。总线过长会让偏移加剧，破坏数据传输的同步性，因此同步总线只能做短。
- **并行信号完整性**。同时并行传输的这些位定时必须相同，但速度越高、线越长，波形越容易因衰减与反射而变形，最快位与最慢位之间的时间偏差随之拉大，多位同时到达的正确性反而难保证。

解决方向就是放宽定时与减少同时翻转的线：改用异步总线、缩短局部总线的长度、或者换成高速串行链路。PCI Express 采用点对点串行传输，既绕开了时钟偏移与并行位间偏差，又减少了信号线数量，还能靠多条通道并联把带宽堆上去，成为现代系统里通用的高速总线标准之一。

## 异步总线：靠握手而不是靠节拍

异步通信不设公共时钟，靠**请求—应答**握手：谁发数据就拉一次请求，收方准备好再拉应答。按应答之后的行为分三种：不互锁（发完请求就松手，最快，最不安全）、半互锁（收方的应答要等发方撤销请求才撤销）、全互锁（双方都要等对方撤销才撤销，最慢最可靠，用于距离不确定或速度差异极大的场合）。异步的长处是设备快慢不一也能凑一起用，每一次传输的时长由实际就绪时刻决定，短处是握手本身要花时间，延迟不可预测，控制协议相对复杂。

同步与异步的取舍一句话能说清：同步像按统一节奏做的团体操，动作整齐、控制简单、灵活性差；异步像自由组合的舞蹈，靠彼此的信号协调动作，谁快谁慢都能配合。

## 异步串行与帧格式

串行通信指数据的各位依次逐位发送或者接收，每一时刻只传送一位。它省硬件成本、便于长距离传送，代价是同等频率下吞吐低于并行。异步通信没有统一时钟来同步收发双方，靠起始位与停止位保持节奏，数据以帧为单位传送。两者结合的产物就是异步串行总线，每个数据帧的发送与接收完全由收发双方的本地时钟控制。

一帧的构成是：起始位（一个低电平，标记帧的开始）、数据位（位数固定，如 7 位或 8 位，按顺序一位接一位发）、可选的奇偶校验位、停止位（一个或者多个高电平，标记帧的结束）。没有数据传输时信号线保持高电平，这就是串行线的空闲状态；发送方要发数据，先把线拉低一段时间发出起始位，再依次发数据位、校验位，最后送回高电平进入空闲，直到下一帧开始。

奇偶校验位用于最简单的错误检测：发送方附加一位，使整帧里 1 的总数为奇数（奇校验）或者偶数（偶校验）；接收方统计收到的 1 的个数，若与约定不符就说明可能出错了。它能发现奇数个位翻转，代价只有一个比特位。

速率用波特率表示，即每秒传输的二进制位数。若一帧由 1 位起始、8 位数据、1 位校验、1 位停止共 11 位组成，那么波特率 115200 时每秒最多传约 10472 个字符——有效数据只占其中 8/11，这就是串行链路里起止位与校验位的固定开销。

## 并行传送与串行传送

并行传送多位同时走，速度快但线路复杂，还要解决位间定时一致的问题，适合短距离板内互连；串行传送一位一位依次走，线路简单、成本低、没有位间偏差，可以把单线频率推得很高，适合长距离与高速链路。现代系统里凡是同时要求速率与距离的接口几乎都收敛到了串行：PCI Express、SATA、USB 都是例子。判断带宽时要区分「一条线的速率」与「整条链路的速率」，串行链路常靠多条通道聚合提速，并行总线则常因复用而打折。

## 七项性能指标

| 指标 | 含义 | 由什么决定 |
| --- | --- | --- |
| 总线宽度 | 一次能传输的数据位数，如 8、16、32、64 位 | 数据线根数 |
| 总线工作频率 | 单位时间内传输数据的次数，单位 Hz | 时钟节拍 |
| 总线带宽 | 单位时间内传输的数据量 | 宽度乘频率 |
| 总线寻址能力 | 能访问的存储单元或者端口数量 | 地址线根数 |
| 总线定时方式 | 同步定时或者异步定时 | 有没有公共时钟 |
| 总线传送方式 | 并行传送或者串行传送 | 一次传几位 |
| 总线负载能力 | 能连接的设备数量及其对电气特性的影响 | 驱动能力与线电容 |

这七项共同决定一条总线的整体性能与适用场景：宽度与频率决定吞吐，寻址能力决定能挂多少东西，定时与传送方式决定快慢设备能否共存，负载能力决定拓扑能铺多大。负载能力强的总线可以多接设备而不影响性能，就像桥梁的承重决定了同时能通过多少辆车。

## 带宽题

总线带宽就是单位时间能搬多少数据，算法是**宽度除以 8，再乘以每秒传输次数**：

```
带宽(B/s) = 总线宽度(bit) / 8 × 工作频率 × 每个时钟传输次数
```

一个 32 位宽、工作频率 100 MHz 的总线，带宽为 32×100÷8 = 400 MB/s；同样宽度下 100 MHz 比 50 MHz 能在相同时间里完成更多次传输，这就是频率这项指标的意义。三个坑：一是宽度指数据线根数，不是地址线；二是地址和数据**共用一组线**（复用）时，一次传输要先发地址再发数据，等效带宽直接对折；三是题目常给「一个传输周期占 n 个时钟」，那每秒传输次数就是频率除以 n，别把频率当传输次数。

时钟周期是最小的节拍，多个时钟拼成一个总线周期（也叫传输周期），几个总线周期拼成一个机器周期，一条指令由一到多个机器周期组成——这条链子背下来，凡是从频率推吞吐的题都能自己搭出来。总线周期对应的是一次完整传输：传地址、传数据、必要的握手与结束，各阶段按节拍排好。

## 仲裁：谁拿到总线使用权

总线仲裁要解决的是多个设备同时请求总线时先满足谁，判据只有两种来源：固定的物理顺序，或者会轮转的计数。三种实现的成本差别就在多用了几根线。

链式查询把所有设备串在同一根优先级链上，离控制器越近的设备优先级越高，好处是线最少，坏处是一处断线后面的设备全部失声。

| 方式 | 线 | 特点 |
| --- | --- | --- |
| 链式查询 | 一根忙线 + 一根菊花链请求线 | 最省线；优先级由物理位置定死，排在最前面的设备天然最高；一处断线全盘失效 |
| 计数器定时查询 | 一根忙线 + 一组设备地址线 | 计数器从 0 数还是从上次的值继续数，决定了优先级是固定还是轮转，可用程序改 |
| 独立请求 | 每个设备各一对请求线、授权线 | 优先级随便定、响应最快，代价是线最多 |

**固定优先级**的毛病是饿死：总线一空闲，永远是最靠前的那个设备拿到。**轮转**（上次服务的下一个优先）保证没人饿死，代价是最坏延迟变大。

## 三个易错点

**把总线宽度当成地址线根数**。算带宽只能用数据线的根数；地址线根数决定的是寻址能力，两者是两个指标，题目里经常同时给出迷惑判断。

**以为同步总线一定能跑到最高频率**。同步总线的频率由最慢的挂接设备和时钟偏移共同压着，加长总线或者混接慢设备都会让可用频率下降；这也是同一条总线上的设备速度必须接近的原因。

**把异步等同于串行**。异步讲的是没有公共时钟、靠握手或者起止位定节拍，它可以是并行的（带请求应答线的并行总线），也可以是串行的（UART 一类的异步串行链路）；并行与串行讲的是同时传几位。两个维度相互独立，组合出四种定时与传送方式。
