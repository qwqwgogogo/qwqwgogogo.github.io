## 一句话

存储层次存在的理由是**速度、容量、成本三者不可能同时最优**。主存站在中间这一层，靠 DRAM 拿到便宜和大，靠刷新换取「掉电期间内容不丢」，靠同步时钟勉强跟上处理器的节奏。

## 支撑层次的四种技术

搭一套层次结构，器件只有四种可选，它们的分工由两个指标定死：访问时间，以及每比特成本。

| 器件 | 访问时间量级 | 每比特成本 | 站在哪一层 |
| --- | --- | --- | --- |
| SRAM | 纳秒级，最快 | 最高 | Cache、寄存器 |
| DRAM | 纳秒级，比 SRAM 慢 | 中 | 主存 |
| 闪存 | 微秒级 | 较低 | 移动设备存储、固态硬盘 |
| 磁盘 | 毫秒级 | 最低 | 海量归档存储 |

这四行就是整章的骨架：**每一种器件都只在某一档上占优，层次结构就是把它们按档位摞起来**。后面所有关于 SSD 取代机械盘、关于新型器件填中间空档的讨论，本质都是在往这张表里塞新的一行。

## SRAM 和 DRAM

| | SRAM 静态 | DRAM 动态 |
| --- | --- | --- |
| 存储单元 | 双稳态触发器，通常六个管子构成两个交叉耦合的反相器 | 一个晶体管加一个电容 |
| 靠什么保存 | 只要通电就一直在 | 电容会漏电，必须定期刷新 |
| 读出时内容 | 不受影响，非破坏性读出 | 电容被放电放光，读一次就没了 |
| 速度 | 快，访问时间基本固定 | 慢，几十纳秒，还要预充电、行列两次送地址 |
| 集成度 / 成本 | 低 / 贵 | 高 / 便宜 |
| 功耗 | 活跃读写时高，待机时只需维持状态 | 单元简单，整体偏低 |
| 用在哪 | Cache | 主存 |

SRAM 读的时候只是感应存储单元的电平，写的时候直接改这个电平，全程不涉及电容充放电，因此读写都快且访问时间稳定。DRAM 的读则是打开访问晶体管、让电容上的电荷流出来，由灵敏放大器判断电荷多少——这股电荷流本身就把电容放掉了，所以每次读都得顺手重写回去。

这就是 DRAM「读即刷新」和破坏性读出两个说法的来源：读出操作天然带了一次重写，而刷新则是另一件独立的事——即使完全不被读，漏电也会让电荷掉到阈值以下，内容就此丢失。

## 刷新只按行做

刷新要重灌的是电容，而阵列里同一行的所有单元共用一条字线，一次选中一行就能把这一行全部读出来再写回去，所以**刷新的粒度是行，列不参与**。

控制器里有一个刷新计数器，顺序产生行地址；整个刷新过程是「读出后写回」，读出的同时就把电荷补回去。常见的时序约束是给一个刷新窗口，比如六十多毫秒内必须把所有行都刷完一遍，行数越多，插入刷新的间隔就得越密——这也是大容量 DRAM 上刷新几乎一直在后台跑的原因。

三种插入时机的取舍：

- **集中刷新**：一段时间里专门停下所有访问，逐行刷完。控制最简单，但那段时间完全不能存取，这段不能服务的空窗叫**死区**，存储器越大、行数越多，死区越长。
- **分散刷新**：每个存取周期后面紧跟一次刷新，永远没有死区，代价是存取周期被拉长一倍，速度白扔一半。
- **异步刷新**：折中方案，把一遍刷新拆成若干次，每隔固定间隔插一行。绝大多数真实机器用的是它——死区被切得极短，每次只挡住一行。

低功耗场景还有自刷新：芯片进入休眠后自己管理刷新，不再需要外部控制器发命令。

DRAM 另一处常考的细节：地址**分行号和列号两次送进同一批引脚**，行选通、列选通各拉一次。所以一片 4096×4096 的芯片只需要 12 根地址引脚而不是 24 根——引脚数就是封装成本和布线难度。

## 加上时钟：SDRAM 与 DDR

早期的 DRAM 是异步的：控制器发命令之后必须等芯片自己准备好，等待时间不确定，流水线只能靠插等待周期来兜。

SDRAM 的改动是让存储器和处理器共用同一个时钟，命令、地址、数据全部对齐到时钟沿上，控制器由此**能精确知道哪一拍该做什么**，不确定性消失了。在此之上还有四项配套：

- **突发传输**：给出第一个地址后，后续数据自动连续送出，不必每个字重新送地址，宽总线的带宽才吃得满。
- **命令排队与预取**：命令提前收下排队，数据行提前激活，请求真到的时候数据已经备好。
- **多 bank 交错**：一个 bank 在预充电或刷新时，控制器把请求发给另一个已经打开的 bank，等待被藏起来。
- **行缓冲**：一行被激活后整行进缓冲，随后同一行内的列访问几乎即时完成。

DDR 的做法是在时钟的上升沿和下降沿都传数据，同一频率下带宽翻倍。所以标称 DDR4-3200 的实际传输次数是每秒 1600 兆次，两个沿各一次凑成 3200。

**内存条上的账**也顺带一条：DRAM 通常不会单独使用，而是把四到十六颗芯片装在同一条 DIMM 上，共同凑出更宽的数据接口，常见的接口宽度是 8 字节也就是 64 位。带宽就是 `8 × 3200 = 25600 MB/s`，这类条子的标称号 PC25600 正是从这个数字来的。

一条 DIMM 内部还会分 rank：共享同一套地址线和控制线的那一组芯片算一个 rank，切分 rank 是为了让地址命令的布线短一些、驱动得动，同时也让控制器能跨 rank 交错访问。

再往移动和封装方向走，还有针对能效优化的低功耗 DDR，以及把 DRAM 层堆叠起来换密度和短走线的三维堆叠工艺。

## 闪存

闪存属于电擦除的那一支，非易失，断电后内容仍在，这一点像磁盘、不像 DRAM。USB 盘、固态硬盘、手机内置存储用的都是它。

它的三条脾气在磁盘那一篇展开：读写按页、擦除按块；块有擦写寿命，所以控制器要做磨损均衡；坏块和制造缺陷要被标记为不可用，配合纠错码把成品率和可靠性抬上去。磨损均衡靠跟踪每块的擦写次数、把新写入优先派给次数少的块来实现，代价是映射表要不停更新，还要牺牲一点原始写入速度。

## 用芯片拼出主存

小容量芯片拼大容量，只有两种基本动作，详细算法在芯片扩展那一篇，这里只留口诀。

位扩展解决数据线不够、地址够的情形：两片并联，地址线和控制线全连在一起，各管一半数据线。

字扩展解决地址不够、位数已经对上的情形：分成多组，低位地址共用，多出来的高位进译码器生成片选，一次只选中一组。

字位扩展就是把两者一起上，芯片总数等于目标位总量除以单片位总量，再拆成「几片一组、共几组」。

一片 `8K×4 位` 的芯片要凑出 8 位字宽，两片一组并联即可；要凑出 `64K×16 位`，就先得两组并成 16 位宽、再按容量铺成若干段地址。

算地址线时记住：**片内地址 = 单片容量取以 2 为底的对数**，多出来的高位一律给译码器做片选。这一条错，整道题就错。

## 存取路径上还有两段延迟

从「地址稳定」到「数据可用」，DRAM 这一侧有两段谁都躲不掉的开销，做性能估算时必须算进去。

第一段是**行激活**：目标单元所在的那一行还没打开时，要先发激活命令，等字线升起来、灵敏放大器把这行电荷分辨出来，这段时间记作行激活到列命令的延迟。如果访问恰好落在已经打开的行上，这段就整个省掉——这就是行缓冲存在的意义，也是为什么「连续访问同一行」远比「跨行乱跳」快。

第二段是**预充电**：要换到另一行之前，必须先把当前这一行的字线关掉、把位线恢复到可以下一次感应的状态，这段时间行是空的、不能被访问。跨行访问越多，这两段叠加得越频繁，实测带宽就会明显低于按频率算出来的峰值。

所以同一条内存条，跑顺序扫描和跑随机访问的等效带宽可以差出好几倍。厂商标的都是「行命中」的理想值，题目给的若是随机访问，就要按行切换的代价重新估。

## 只读存储器和它的家族

只读存储器不是只能读——它是掉电不丢内容，靠这个特点放固件和微指令。家族的区别全在「怎么擦、怎么写」：

| 类型 | 写入方式 | 擦除方式 |
| --- | --- | --- |
| 掩膜 ROM | 制造时一次固化 | 不可擦 |
| PROM | 一次可编程 | 不可擦 |
| EPROM | 可编程 | 紫外线整片擦除，要取下芯片 |
| EEPROM | 可编程 | 电擦除，可在线按字节改 |
| 闪存 | 按页编程 | 按块电擦除，是 EEPROM 的大规模版本 |

闪存按块擦除这件事很关键，它是固态硬盘和移动存储的地基，也正是「擦除粒度比写入粒度大」这一堆麻烦的源头。

## 为什么这套层次管用

因为局部性——刚用过的和挨着用的大概率还会再被用到。上层的 SRAM 装热点、中层的 DRAM 装全部、再下面的闪存和磁盘装不常碰的数据，程序感受到的成本接近最便宜那层，速度接近最快那层。

Cache 那一节的三种映射和平均访问时间算的是这套逻辑的算法部分；芯片扩展算的是它的物理部分；而刷新、行缓冲、突传这些细节，决定了下面那层到底能有多快——上层再怎么赌，下层太慢也兜不住缺失惩罚。
