## 一句话

存储层次存在的理由是**速度、容量、成本三者不可能同时最优**。主存站在中间这一层，靠 DRAM 拿到便宜和大，靠刷新换取「掉电期间内容不丢」。

## SRAM 和 DRAM

| | SRAM 静态 | DRAM 动态 |
| --- | --- | --- |
| 存储单元 | 双稳态触发器，几个管子 | 一个晶体管加一个电容 |
| 靠什么保存 | 只要通电就一直在 | 电容会漏，必须定期刷新 |
| 速度 | 快 | 慢（还要预充电、行列两次送地址） |
| 集成度 / 成本 | 低 / 贵 | 高 / 便宜 |
| 用在哪 | Cache | 主存 |

DRAM 读出来会把电容放电放光，所以**读操作本身自带重写**，这也是它「读即刷新」和破坏性读出的说法来源。刷新则是另一件事：即使不读，漏到阈值以下内容就丢了，所以要按**行**周期性重灌。刷新周期是整片刷完一遍的时间窗，行地址数决定要刷多少次；列地址不参与，因为漏的是那一行的电容。

三种刷新时机的取舍：

- 集中刷新：一段时间内专门刷所有行，控制最简单，但那段时间完全不能访问存储器，这段不能服务的空窗就叫死区，存储器越大死区越长。
- 分散刷新：每个存取周期后面紧跟一次刷新，没有死区，代价是存取周期被拉长一倍，速度白扔一半。
- 异步刷新：两者折中，把刷新次数平摊到一段时间里，每隔固定间隔插一行——绝大多数真机器用的就是它。

DRAM 还有一处常考的细节：地址是**分行号和列号两次送进同一批地址引脚**的（行选通信号、列选通信号各拉一次），所以一片 4096×4096 的芯片只需要 12 根地址线，而不是 24 根——引脚数就是封装成本。

## 用芯片拼出主存

小容量芯片拼大容量，只有两种动作：

位扩展是数据线不够、地址够——比如用 `8K×4 位` 的芯片凑出 8 位字宽，两片一组并联，地址共用车片选信号。字扩展是地址不够——芯片位数对，但容量要翻倍就得多组，多出来的地址位进译码器生成片选，一次只选中一组。字位扩展就是两者一起，所需芯片数 = `(目标容量 / 单片容量)`，按「几片一组、共几组」拆开算即可。

算地址线时记住：**片内地址 = 单片容量取以 2 为底的对数**，多出来的高位一律给译码器做片选。这一条错，整道题就错。

## 只读存储器和它的家族

只读存储器不是只能读——它是掉电不丢内容，靠这个特点放固件和微指令。家族的区别全在「怎么擦、怎么写」：掩膜一次写死；可编程只能写一次；紫外线擦除要拿下来照；电擦除可以在线改；闪存是电擦除的大规模版本，按页读写、按块擦除，是固态硬盘和 U 盘的地基。

## 为什么这套层次管用

因为局部性——刚用过的和挨着用的大概率还会用。上层的 SRAM 装热点、下层的 DRAM 装全部、再下面磁盘装不常碰的，程序感受到的成本接近最便宜那层，速度接近最快那层。Cache 那一节的三种映射和 AMAT 就是这套逻辑的算法部分。
