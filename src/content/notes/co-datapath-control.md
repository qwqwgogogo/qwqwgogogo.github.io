## 一句话

数据通路就是指令流经的那条硬件路线——存储器、ALU、寄存器堆、连接线摆在一起；控制信号就是每拍告诉这些部件「现在做什么」的那几位电平。

## 五个阶段

```
IF  取指令，PC + 1 条
ID  译码 + 读寄存器堆
EX  ALU 算地址或算结果
MEM 访问数据存储器
WB  写回寄存器堆
```

单周期就是每条指令都在一个时钟周期内走完这五段，于是时钟周期必须由最慢的那条指令定死。算数、比较、分支、取数、存数共用同一套部件，差别只体现在**怎么接线**和**写回什么**。

## 两类逻辑的分界

组合逻辑没有记忆，输出只由当前输入决定——门电路、译码器、多路选择器、ALU 都是它。多路选择器的作用是**从几路输入里挑一路**，靠几位选择信号决定，整条数据通路能复用全靠它。

时序逻辑带记忆，输出还取决于当前状态，基本单元是触发器；寄存器、PC、存储器都是。写寄存器只发生在时钟边沿，所以「同一周期里两个部件想写同一个寄存器」必须靠硬件保证不撞。

组合逻辑出控制信号，时序逻辑存状态——控制器的任务就是在每一拍算出这一拍所有多路选择器该选哪一路。

## 取数和存数多出来的三样

和加法指令比，访问存储器的指令在数据通路里多出三块硬件：一个读存储器的部件、一条把存储器读出的数据引回写口的线、以及**符号扩展**部件——立即数字段只有 16 位，而寄存器是 32 位，有符号数要在高位补满符号位才拼得起来。无符号数补 0，有符号数补符号位，补错了负数会变成极大的正数，这是选择题最爱下的套。

## 控制信号表

| 信号 | 作用 | 取数指令为什么是它 |
| --- | --- | --- |
| RegDst | 写回目标是第几个寄存器号 | 立即数不是寄存器号，所以选低位字段 |
| ALUSrc | ALU 第二个操作数取寄存器还是立即数 | 算地址要用「基址 + 偏移」，选立即数 |
| MemRead / MemWrite | 让不让访问存储器、读写哪一头 | 只读，不写 |
| MemtoReg | 写回的数据来自 ALU 还是存储器 | 来自存储器 |
| Branch | 相等就跳 | 由 ALU 的零标志决定 |
| ALUOp | ALU 做加、做减还是别的 | 加法算地址 |

六个信号里，RegDst 决定写回哪一个寄存器，ALUSrc 决定 ALU 的第二个操作数从哪来。

MemtoReg 决定写回的是 ALU 算出的值还是存储器读出来的值，Branch、MemRead、MemWrite 则是三个「要不要做这件事」的开关。

ALUOp 是发给 ALU 的操作码，告诉它这一拍做加法还是减法。别把这张表当填空背，它是**同一个加法器被多种指令共用**的证据：硬件不变，变的只是这几十位电平。

## 指令集架构和微架构不是一回事

指令集架构规定「有哪些指令、编码长什么样、程序员看到什么」；微架构是同一份指令集架构在硬件上的具体实现。同一套指令集架构可以做成单周期、多周期、流水线甚至乱序，编译出来的二进制照样能跑——这就是把两者分开记的价值：性能是微架构给的，兼容性是指令集架构给的。
