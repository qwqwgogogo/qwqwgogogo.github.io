## 为什么是二进制

处理器内部的电路属于数字电路，它能可靠地区分并保持两种稳定状态：高电平与低电平，分别记作 1 和 0。选二进制不是因为十进制不方便，而是因为两种状态之间的电压间隔最大，采样时刻只要越过阈值就能判对，抗干扰余量最足。逻辑 1 表示信号被激活、存在或为真，逻辑 0 表示未激活或为假。过渡期间的电压是不确定的，因此设计者必须规定采样时刻和阈值，保证在这段时间内电路已经稳定到某一确切状态。

按是否含有存储器件，逻辑电路分成两大类。组合逻辑不含存储元件，输出只由当前输入决定，内部不留任何状态，输入一变输出就跟着变，门电路、译码器、多路选择器都属于它。时序逻辑含有触发器或寄存器这类存储元件，输出既取决于当前输入也取决于内部保存的状态，对输入的反应要等到时钟沿或别的触发条件，寄存器、计数器、有限状态机都属于它。这一句分界是后面读懂状态单元和流水线的地基。

## 真值表与逻辑方程式

组合逻辑的行为能被穷举：n 个输入共有 2^n 种取值组合，把每种组合对应的输出列成表，就是真值表。两个输入就有四行，五个输入变成三十二行，规模按 2 的幂膨胀，很快就列不动了。工程上的做法是把输出恒为 0 的行省掉，只把有意义的那些行写出来，再用代数式或图形方法化简。

描述组合逻辑的另一条路是逻辑方程式，用的运算是布尔代数。三种基本运算：或运算记作 `A + B`，只要有一个输入为 1 输出就为 1；与运算记作 `A · B`，全部输入为 1 输出才为 1；非运算记作 `A'` 或在变量上加一横，把 1 变 0、把 0 变 1。这里的加号和点乘只是符号借用，和算术里的加法乘法没有关系。

常用定律按名字记全：交换律 `A + B = B + A`、`A · B = B · A`；结合律、分配律 `A · (B + C) = A·B + A·C` 与 `A + B·C = (A + B)·(A + C)`；德摩根定律 `¬(A·B) = ¬A + ¬B`、`¬(A+B) = ¬A · ¬B`；同一律 `A + 0 = A`、`A · 1 = A`；零一律 `A + 1 = 1`、`A · 0 = 0`；吸收律 `A·(A+B) = A`、`A + A·B = A`；同或自反律 `A + A = A`、`A·A = A`。化简时最常被误用的是分配律的第二条，普通代数里没有对应的形式。

真值表和逻辑方程式是同一件事的两种写法，可以互推：从真值表把所有输出为 1 的行写成与项再相或，得到乘积和；把输出为 0 的行写成或项再相与，得到和之积。行数太多时用卡诺图合并相邻项，目的是减少门数量和门的输入端数。

## 门与反相器的完备性

与门实现全真则真，或门实现有真则真，非门实现取反，反相器在图上有简便画法：不单独画一个门，而在需要取反的那条输入线或输出线上加一个小圆圈。由于与、或满足交换律和结合律，可以直接做多个输入的与门和或门。

只用一种带取反功能的门就能搭出全部逻辑函数。以或非为例，把两个输入各自取反后送入或门，再对结果取反，就等价于与门，因为「两个都真」的反面「至少一个假」被再次取反后正好回到「两个都真」。同样的构造可以做出或门、异或门，因此与非门、或非门各自构成一套完备集，这叫通用门。实际芯片偏爱或非、与非两类，正是因为一种门走天下，版图规则和良品率都更好处理。

## 译码器：把编码还原成一根有效线

译码器是搭建较大逻辑块时的常用部件。它的输入是一组二进制编码，输出是 2^n 条线，任何一组输入下恰好有一条输出被置 1，其余全为 0；若输入的十进制值为 i，那么被置高的就是第 i 条输出。三输入八输出的器件因此被叫作 3-8 译码器，输入 000 时第一条输出有效，输入 111 时最后一条有效，中间按二进制顺序一一对应。

| 输入 | 有效输出 |
| --- | --- |
| 000 | Out0 |
| 010 | Out2 |
| 101 | Out5 |
| 111 | Out7 |

把带使能端的译码器反过来看，它的作用就是根据地址把一路输入送到多条输出中的一条，这正是数据分配器，也称作解复用器，与多路选择器构成方向相反的一对。数据通路里给寄存器堆选择写入目标、给存储器选择片选，用的都是这类结构。

## 多路选择器：硬件版的按需选路

多路选择器在处理器图里出现得最频繁。它的输出取自若干数据输入中的某一个，取哪一个由选择信号决定：两输入的选择器只需一位控制信号，控制为 0 选第一路，为 1 选第二路；输入更多时选择信号的位数按 log2 增长，八选一就要三位。

用门电路写它的行为并不神秘，输出就是被选中那一路与其余各路取反的与项之和。三位选择信号可以写成 case 列举的方式描述，描述硬件时要保证所有取值都有确定的输出分支，否则未覆盖的取值会推导出 latch，这在组合逻辑里是典型的错误。

一个 32 位宽的选择器不是单独设计的机械件，而是把 1 位选择器复制 32 份并排摆放。理由是设计上不做按位宽分别定制，而是同一单元堆叠，这样版图和验证都能复用。寄存器堆的写入数据来源、ALU 第二操作数来源、程序计数器的更新来源，用的都是这种位宽为 32 的选择器阵列。

## 两级逻辑与可编程逻辑阵列

任何逻辑函数都能写成两种两级形式。乘积和形式也叫与或式，把若干个与项相或，每个与项对应真值表里一个输出为 1 的行，例如三变量的函数写成 `F = A·B·C' + A·B'·C + A'·B·C`，含义是三组特定取值里任意一组出现时 F 为 1，其余取值下为 0。和之积形式也叫或与式，把若干个或项相与，每个或项对应真值表里一个输出为 0 的行，只有全部或项同时为真结果才为真。两种形式之间可以互换，选哪种取决于面积、速度和功耗哪一项更敏感，综合工具会自动做出选择。

乘积和形式天然对应可编程逻辑阵列。这种器件由两级可编程结构组成：第一级是与门阵列，输入变量及其取反信号都能作为与门的输入，每个与门产出一个乘积项；第二级是或门阵列，把若干乘积项组合成输出。改变两级之间的连线就能实现不同的布尔函数，硬件结构不用重做。它的现代继承者是现场可编程门阵列，集成度和规模都远超前者，但先用与阵列生成乘积项、再用或阵列求和的基本思路仍是理解组合逻辑实现的标准模型。

## 逻辑单元阵列与总线选择

按整个字并行处理的组合操作要用阵列结构：32 位按位与就是 32 个独立的与门同时工作，每一位互不影响，所有位的输出拼成一个新的 32 位字。位与位之间没有进位关系，这是逻辑运算比算术运算好并行的根本原因。

总线是一组被当作一个逻辑信号使用的数据线，宽度决定一次能搬多少位，32 位总线一次搬一个字。机器内部常常要在几条总线之间做选择，靠的就是多路选择器：每路输入是一条总线，选择信号决定当前哪一条接到输出。多个部件共享同一物理线路时还要解决谁先用的问题，这就引出仲裁机制；地址、数据、控制几类总线之间的配合，则是访存操作的时序内容。

把整个字做成阵列、把多条总线用选择器复用，这两件事合起来就是后面所有数据通路图的基本画法。

## 一个小函数走完全流程

设计一个三输入判定电路：输入里 1 的个数为奇数时输出 1，这正好是全加器里和位的规则。八行真值表中输出为 1 的只有 001、010、100、111 四行，按乘积和规则直接写出 `F = A'·B'·C + A'·B·C' + A·B'·C' + A·B·C`。这四个与项两两都不相邻，卡诺图上无法合并，说明两级与或结构省不掉任何一项。换一个写法把它看成两次异或 `F = (A ⊕ B) ⊕ C`，门数立刻变少，但电路的层数和延迟随之改变。同一条逻辑功能，用乘积和、用或与、用异或链三种写法，面积和速度各不相同，这就是为什么要先列真值表再决定实现形式，而不是反过来。

## 从门到图：读通路图的三条约定

这一层的基础知识最后要落到读图上。第一，实线走数据、虚线走控制，控制线只决定选择器接通哪一路，本身不携带数据值。第二，凡是某个目的地可能有多个来源，图上必然画一个多路选择器，它旁边那根控制线就是后面控制单元要产生的信号，读图时看到选择器就应当立刻反问「这个信号为 1 和为 0 分别走哪条路」。第三，多位信号用粗线表示总线，交叉处有黑点才算相连。把这三条约定吃透，后面从 1 位 ALU 到整条单周期通路的每一张图都是同一套读法，不需要重新记符号。
